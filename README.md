# Collegare Talent Management — Website

Static website for Collegare Talent Management.

## Structure

- `index.html` — Site index / preview page
- `homepage.html` — Main homepage
- `about.html`, `for-brands.html`, `for-creators.html`, etc. — Site pages
- `shared/` — Shared styles (`tokens.css`) and React components used across pages
- `pages/` — Page-specific React components

## Stack

Plain HTML + CSS with React components compiled in-browser via Babel Standalone. No build step required.

## Deployment

Deployed via Vercel. Pushes to `main` auto-deploy.
